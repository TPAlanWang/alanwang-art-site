未竟之夢，抑是空中樓閣？── 《爵士週末Jam Session 入場消費執行方案》

此系列紀錄我那些規劃完成，但沒能實行的企劃，安放在此，讓他們告一個段落。

這份企劃，是一個透過舉辦長期系列活動，多方合作，塑造《若晞茶空間》品牌形象的宏大夢想之起點。

若晞首次嘗試舉辦的音樂性藝文活動《秋樂和茗・茶空間的爵士夜》獲得成功後，我們決定要沿用這次經驗，將這個模式常態化，持續舉辦音樂活動，建立若晞的品牌特色。

在春節前夕，同事提出擴大舉辦的想法：透過招攬攤販合作，將現有的爵士樂演奏晚會與小市集結合，讓來客有更豐富的食物選擇；更熱鬧的活動現場，也能提升對路人的吸引力，開發週邊的新客源。

因此，經過討論後，我構思了一個方案，將更注重氛圍、想更沈浸體驗若晞環境的核心客，與單純喜歡熱鬧的過路客加以區隔：

  • 主屋庭院：四周有圍牆圍起，隱密性較高，因此將舞台架設於此，當天須購票入場，票價可部分折抵消費，預約享早鳥優惠，且提供限定此區觀眾購買的若晞獨家茶點。

  • 前院：此區域開闊，為開放空間（實際上就跟公園一樣），招攬多家廠商在此設攤，架設音響同步放送庭院的現場演出，形成自由入場的小型市集。而整個活動的飲品僅限若晞提供，因此我們也會在前院設置一個簡易攤位。

  • 演出模式：以 Jam Session[1] 的形式舉辦，既能提供樂手演出舞台，也能稍微降低聘請樂團的人事成本。

確定活動方針後，我詳細設計了針對主屋庭院部分的入場消費執行方案，包含場地可容納人數、座位規劃、目標收入設定，以及演出樂手的演出費計算方式。

以下是詳細清點場地空間，彙整過去活動經驗與獲利目標後所撰寫的完整執行企劃書內容：

爵士週末Jam Session 入場消費執行方案

  • 場地

    • 大木棧板
      • 數量：6
      • 可坐人數：3~4人
    • 小木棧板
      • 數量：4
      • 可坐人數：2人
    • 其他
      • 長椅：可坐2~3人
      • 長桌椅：可坐6~8人
      • 碎石區、草皮：擺放4張折疊椅搭配1張小桌，可擺5組
      • 樂手休息區：創辦人茶師座位後方室外空間，可擺5~10張折疊椅

  • 座位規劃

    • 大木棧板以空間較舒適的三人座計算，6x3=18位
    • 小木棧板4x2=8位
    • 其他座位共11位
    • 碎石區、草皮折疊椅共20位
    • 樂手休息區共10位
      以上共67個座位

  • 消費方案 設定每位入場顧客收費300元，樂手收費250元，並消費一瓶茶飲（200元起），以此設計以下消費方案：

    • 入場費400元，折抵消費200元，樂手折抵250元，實際收入150~200元
    • 所有茶飲價格較平常售價提高100元
    • 低消一瓶茶飲
      以上費用相加後，實際入場收費250~300元，一瓶茶飲200元起

  • 翻桌方案

    • 活動採預約預付制，活動開始前2小時停止接受報名
    • 演出開始後（17:00）開放現場候位
    • 現場候位入場費用提高100元

  • 樂團演出費方案 滿座情況入場費可獲利67x300=20100元，以入場費的全額或部分收入支付演出費，可以促進樂手主動宣傳活動（觀眾越多演出費越多）。以此規劃演出預算如下：

    • 方案一：入場費全額支付演出費=20100元
    • 方案二：每位顧客入場費的其中200元支付演出費67x200=13400元
    • 若入場人數未達目標，保底支付12000元演出費

企劃整理完成後，我馬上拿給同事及店長看，一邊講解我設計的方案內容。他們都表示沒有問題，就這麼辦👍

提出要擴大舉辦的那位同事，說他認識在台南多次舉辦大型市集的主辦人，等我們忙完春節這波，再去找他諮詢、請他介紹廠商給我們，絕對穩妥！因此前院的招商與安排，就全權交給他負責。

經過了忙碌的春節，以及精彩的《元宵爵士夜》後，我向那位同事詢問招商進度，他居然改口說，我們的方案要辦成小市集可行性很低，且他從來就沒有想過要辦市集，只是想招幾個賣食物的小攤販合作，讓庭院的客人有多一點食物可以選擇而已。

？？？

我直接當場爆炸🤬 當初就是你說要擴大舉辦市集，提升對路人的吸引力，開發週邊的新客源，甚至串連附近的飯店，長久經營，成為在地特色，我才設計一個配合前院市集的庭院入場消費方案！現在又變成你從來就沒有想過要辦市集了？那我們之前都在討論什麼？企劃書白紙黑字都寫下來了，你怎麼解釋？？

同事又是一語不發，開始洗杯子、擦檯面，做起與討論無關的事情。無法繼續說下去，這份企劃就此成為了我的「未竟之夢」的最新、也是最後一員😢

而店長全程參與了之前的討論，也目睹這次的衝突。事後我詢問她的看法，她也認為是那位同事有問題，前後說詞不一。
然而，店長對此卻沒有採取任何處置！就是因為管理層總是這樣的毫無作為，才會讓同樣的狀況一再發生😒
看看我的「未竟之夢」系列，這都來到第六篇了🙄

在我終於認清了我為若晞所做的事情大概都是徒勞之後，這份企劃承載的夢，對我來說，也已失去了意義。

之前，我曾在一次次與同事交手的經驗中領悟出「只要不需要跟別人合作，我的計畫就不會被破壞」。然而，事過境遷，這次又不知不覺地走回老路，最終落得同樣的下場…難道說，這就是傳說中的「人類從歷史中學到的唯一教訓，就是人類無法從歷史中學到任何教訓」嗎😢

Jam Session 為爵士樂手重要的社交活動，由主辦方提供舞台，讓與會樂手自由報名，進行未經排練的現場演出。由於台上的演出樂團皆為當場臨時組成，往往能碰撞出意想不到的火花，是非常適合認識新樂手，組成樂團的絕佳機會🎶
